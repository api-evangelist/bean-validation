Jakarta Validation 4.0 is on its way,
as the release plan for this version was approved exactly one month ago on May 6!




What to expect from Jakarta Validation 4.0?


The highlights of this release plan are as follows:




This version of the specification will require Java SE 21 or higher.


Prepare for removal of the legacy approach to mark container elements for cascading validation, i.e. @Valid List list;.
The next major version will consider such code to be requesting the cascading validation of the List, and not its elements.
