Good news for those of you who want to certify the compatibility of a Bean Validation implementation (and its API JAR) against Java SE 8. We have released updates to the Bean Validation TCK 1.0 and 1.1; The versions are 1.0.7.GA and 1.1.3.Final, respectively. Both TCK releases come now with a version of the API signature file which works with Java SE 8.
